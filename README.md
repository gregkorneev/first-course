# База знаний первого курса

Мобильный справочник для подготовки к общему тестированию по четырём дисциплинам:

- «Информатика»;
- «Основы программирования» — C++;
- «ООП» — C++;
- «Архитектура автоматизированных систем обработки информации и управления» (АСОИУ) — C#.

**Сайт:** <https://gregkorneev.github.io/first-course/>

## Что находится в репозитории

```text
index.html                         перенаправляет на базу знаний
knowledge-base/index.html          весь сайт: содержание, стили и фильтры
.github/workflows/deploy-pages.yml автоматическая публикация GitHub Pages
AGENTS.md                          правила обновления для ИИ-агентов
```

Сайт статический: не требует Node.js, пакетного менеджера, сборки или базы данных. Его можно открыть локально через `knowledge-base/index.html`.

## Как пользоваться

В верхней части сайта доступны поиск и два фильтра: язык и дисциплина. Начинайте с нужной дисциплины, затем ищите термин или раскройте вопросы в разделе «Самопроверка» только после собственной попытки ответить.

## Как обновить базу

1. Меняйте содержимое в `knowledge-base/index.html`.
2. Новому разделу назначьте `data-language` и `data-discipline`, чтобы он работал с фильтрами. Допустимые дисциплины: `programming`, `oop`, `asoiu`.
3. Проверяйте JavaScript:

   ```sh
   node --check <(sed -n '/<script>/,/<\/script>/p' knowledge-base/index.html | sed '1d;$d')
   ```

4. Закоммитьте изменения и отправьте их в `main`. GitHub Actions автоматически обновит сайт.

## Публикация

GitHub Pages публикуется workflow-файлом `.github/workflows/deploy-pages.yml` после каждого push в `main`. Публикуется только содержимое этого лёгкого репозитория; локальные первоисточники в workflow не участвуют.
