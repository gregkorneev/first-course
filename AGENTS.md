# Правила для агентов

## Назначение

Это статическая база знаний для подготовки к общему тестированию первого курса. Дисциплины: информатика, основы программирования (C++), ООП (C++) и АСОИУ (C#). Приоритет — полнота охвата тем, точность терминов, удобство повторения на телефоне и отсутствие лишних зависимостей.

## Границы репозитория

- Редактируемый продукт: `knowledge-base/index.html`.
- Корневой `index.html` только перенаправляет на сайт; не дублируйте там содержание.
- Локальные исходники `Lecture-2-main/`, `Lecture-Theory_OP-main/`, `course-architecture-main/` намеренно игнорируются Git. Не добавляйте их, PDF, ZIP-архивы или сгенерированные копии в коммиты.
- Не добавляйте фреймворки, сборку или зависимости ради небольшой правки. Сайт должен оставаться одним автономным HTML-файлом.

## Таксономия

Используйте только четыре значения `data-discipline`:

- `informatics` — «Информатика»;
- `programming` — «Основы программирования» (C++);
- `oop` — «ООП» (C++);
- `asoiu` — «АСОИУ» (C#).

Для языка используйте `cplusplus`, `csharp` или `theory`. Новый материал должен иметь оба атрибута, иначе фильтры не смогут его показать корректно.

## Стандарт изменений

- Пересказывайте материал, не копируйте лекции целиком.
- Для каждой новой большой темы добавляйте: короткое определение, важное различие/условие применимости и, когда полезно, небольшой пример.
- Расширяйте «Самопроверку» вопросами, которые проверяют понимание, а не дословное запоминание.
- Сохраняйте доступность: семантические заголовки, читаемый контраст, кликабельные элементы не меньше 40 px на мобильном экране.
- После изменения JavaScript запускайте `node --check` для блока `<script>`.

## Публикация

Push в `main` запускает GitHub Pages. Перед отправкой убедитесь, что в индекс не попали игнорируемые исходные материалы.
